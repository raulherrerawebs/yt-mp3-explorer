# YT MP3 Explorer

Descarga música de YouTube y la convierte automáticamente a MP3. Incluye reproductor, descarga de playlists y lotes.

## Actualizaciones
El programa consulta `update.json` de este repositorio. Cuando hay una versión nueva aparece el botón
**"Actualizar"**: descarga `YT-MP3-Explorer.exe`, lo reemplaza y se reinicia solo.

En la app: **Ajustes → Origen de actualizaciones → `raulherrerawebs/yt-mp3-explorer`**.
